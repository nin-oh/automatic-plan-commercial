# Samples

Drop your reference `.pptx` here:

- `plan_commercial_exemple.pptx` — the MIO *Canal Gros* deck (147 slides).

Once added, the generator will:
1. Extract the background / template slide from it.
2. Derive the Excel schema (one row = one product slide).
3. Build a demo `plan_commercial_demo.xlsx` that reproduces the deck.
